# Inspeção visual M01

Marca: captura desktop 1440 × 1200 legível, com ficha oficial e formulários recolhidos.
Biblioteca: o Chrome headless impôs viewport mínimo e cortou a captura original
M01-mobile.png solicitada em 420 px. Ela foi preservada conforme o hash registrado
no checkpoint. A captura adicional M01-mobile-600.png (600 × 1100), inspecionada
após o checkpoint, mostra navegação, avisos, seletores recolhidos e estado vazio
sem cortes. Essa captura adicional não integra os hashes do checkpoint original.

O navegador integrado não estava conectado. Nenhum teste interativo de navegador
é alegado: os fluxos de formulário foram exercitados pelos testes HTTP. A inspeção
visual não equivale a uma auditoria completa de acessibilidade. Dados da Marca
são fixtures explícitas em /private/tmp, sem alterar o acervo comercial.
